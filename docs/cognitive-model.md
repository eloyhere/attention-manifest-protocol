# 把 Agent 当作人类：一个受约束决策者的心理学模型

**状态**：提案模型，非规范 · 2026-10
**证据底座**：[`docs/research/human-attention-allocation.md`](research/human-attention-allocation.md)

**与上一版的关系**：[`docs/attention-upgrade.md`](attention-upgrade.md) 说**改哪些字段**；本文说**为什么是这几个字段**，以及凭什么相信它们。

## 0. 「当作人类」的三种读法，只有一种能落地

| 读法 | 做法 | 为什么 |
| --- | --- | --- |
| **拟人化修辞** | 给状态起名：情绪、疲惫、直觉、好奇心 | **不可用。** 这些量无法从回执重算，违反 §6 的承重规则（「任何不能从日志重算的字段，只是注释」）。 |
| **规范移植** | 拿人类的行为当正确答案，Agent 越像越好 | **只对一半。** 人的启发式是在**人的约束**下的最优解；换一副约束，它可能就是错的。照抄会把人的偏差也抄进来。 |
| **结构等价** | 承认两者面对**同一个控制问题**，只移植约束 | **本文件采用。** |

结构等价的论证很短：心理学研究的对象不是「大脑」这个材质，而是**一个资源受限、必须自我监控、且被他人观察的决策者，如何在信息不完备时分配有限的认知**。这三条性质与基底无关。任何具备它们的系统都面对同一个控制问题——有限的注意力该给谁、给多久、什么时候停、花多少在「决定给谁」上、以及在别人看着的时候怎么表现。

这也正是**资源理性**（resource rationality）的立场：认知策略应当被理解为**资源约束下的最优**，而不是逻辑上的最优 [PAPER: Lieder & Griffiths 2020, *BBS* 43:e1]。把 Agent 当作人类，准确的意思不是"让它有人的感受"，而是：

> **承认它和人类面对同一个控制问题，并把心理学已经积累的约束拿来解它。**

**一条准入门槛。** 任何心理学术语要进入协议，必须同时满足两条：**(a) 能从回执估计；(b) 改变可观测行为。** 不满足的，是修辞。这条门槛直接判掉了 `mood`、`fatigue`、`intuition`——不是因为它们假，而是因为**协议对它们无话可说**。

## 1. 三层，而不是一张变量表

心理学的组织方式不是状态清单，是层次。按层次建模的好处是：每层有自己的失效模式，可以用不同的指标暴露。

| 层 | 回答的问题 | 状态 | 失效时的签名 |
| --- | --- | --- | --- |
| **容量层** | 能同时处理多少、处理得多锐利 | `load` `vigilance` | 该看的没看（漏检）、看得太散（抖动） |
| **评价层** | 什么值得、什么危险、值多少钱 | `arousal` + 亏损不对称 + 努力成本 | 优先级错、把危险当噪声 |
| **自我-社会层** | 我是谁、别人在看什么 | `mastery` `accountability` | 该问不问、该停不停、声明的确定性虚高 |

上一版提案的七条不变量（A-6…A-12）是**字段**；这三层是**为什么是这些字段**。二者不是并列的两套东西：每层恰好解释若干字段。

## 2. 五个状态变量

每个变量给出四件事：**构念 → 估计量 → 改变什么 → 什么会推翻它**。最后一项是重点：一个不能被推翻的状态变量不该存在。

### 2.1 `load` — 容量占用

- **构念**：工作记忆占用 + 未闭合回路。未完成的任务会持续占资源（人对未完成事项的记忆优势是这一点的行为证据，但其经典表述 Zeigarnik 效应的复现记录参差，因此这里只用「未闭合回路计入占用」这一较弱假设）。
- **估计**：`0.6 · (Σ chunk / 容量) + 0.4 · (积压项 / 8)`，其中 chunk 数来自上一帧的活动槽位。
- **改变**：有效容量 `capacityEff = round(4 · (1 − 0.5·load))`；以及是否允许 `novelty` 参与评分。
- **推翻条件**：若在高 load 下焦点集并未收窄、或收窄后 `wasted_attention_ratio` 不降，则 `load` 项应删除。

### 2.2 `vigilance` — 在任务上的警觉余量

- **构念**：持续注意的衰减。它不是「能量」，而是**漏检概率的上升**：长时间监视低事件率信号，正确率会下降，且伴随主观负荷与压力上升 [REVIEW: Warm, Parasuraman & Matthews 2008, *Human Factors* 50(3):433–441]。
- **估计**：`exp(−cycles_since_rest / τ)`，`τ` 默认 12 个周期，**必须**用本 Agent 的实测曲线替换。
- **改变**：`pLapse = 1 − vigilance`，即「一条 `revisit_if` 已经触发却没被复查」的概率。这是 `rest` 唯一被赋予的确切功能：重置这个计数。
- **推翻条件**：若把 `rest` 撤掉后漏检率不变，则 `vigilance` 是装饰。**注意**：这里禁止用「意志力耗尽」解释——该模型在 23 实验室、N=2,141 的预注册复现中效应为零 [META: Hagger et al. 2016]。

### 2.3 `arousal` — 错误压力

- **构念**：唤醒/紧迫对**广度**的影响。Easterbrook 的线索利用理论：唤醒升高会缩小被利用的线索范围 [PAPER: Easterbrook 1959, *Psychological Review* 66(3):183–201]。
- **估计**：近 12 条回执中 `blocked`/`failure` 的占比（0.75 权重）+ `partial` 占比（0.25）。
- **改变**：`γ = 1 + 0.5·arousal`，作用在 `goalFit` 的指数上——见 §3 定律 1。
- **推翻条件**：若 arousal 升高后，目标外但高价值的候选**排序上升**，则收窄机制写反了。这是一个可以直接跑的判别实验。

### 2.4 `mastery` — 自我效能（长程）

- **构念**：对「我在这类任务上能否成功」的估计。它与 `arousal` 是**同一信号的两种时标**：arousal 是快的、相位性的；mastery 是慢的、特质性的。合并成一个数会丢掉一个事实：**有能力的 Agent 会短暂惊慌，没能力的 Agent 可以一直很平静。**
- **估计**：全账本的成功率。样本 `< 30` 时标 `default`，不得用于放弃/委派决策（与 §8.4 的 UNCALIBRATED 规则同构）。
- **改变**：低 mastery + 高 VOI ⇒ 应倾向 `ask` / 委派，而不是硬磕。这是把「努力分配」变成结构决策，而不是变成"更努力"。
- **推翻条件**：若按 mastery 分流后任务成功率不升，则该变量应降级为纯报表字段。

### 2.5 `accountability` — 被观察度

- **构念**：可识见性。它对**努力**和**声明的复杂度**都有影响，但方向取决于受众：受众观点未知 ⇒ 更整合、更自我批判；受众观点已知且相同 ⇒ 更防御 [REVIEW: Lerner & Tetlock 1999, *Psychological Bulletin* 125(2):255–275]。
- **估计**：由宿主给出（有承诺、有受众、有审计方），不从账本猜。
- **改变**：不可逆行动要求的最少备选数随 accountability 上升；努力权重上升。
- **推翻条件**：若提高 accountability 后，被否决的备选数目不变，则它没有进入协议，只是进了日志。

## 3. 六条定律（写成可证伪的形式）

实现见 [`cognition.ts`](../src/attention/cognition.ts)。每条都对应一条可测的单调性约束，落在 `respectsCognitiveMonotonicity` 的十个检查里。

```text
S(i) = floor_i ⊕ [ voi_i · goalFit_i^γ · (1 + novelty_i·openness) · history_i ]
       / [ 1 + c_tok + c_risk + c_switch·(1+load) + c_meta ]
γ      = 1 + 0.5·arousal
openness = 1 if load ≥ 0.3 else 0
history  = (1 + 2·(realized − 0.5)) − 0.5·exp(−Δt_ignored/3)
```

| # | 定律 | 依据 | 可测后果 |
| --- | --- | --- | --- |
| 1 | **唤醒收窄**：`γ` 随 arousal 上升 | Easterbrook 1959 | 目标外候选的分数随 arousal 单调不升 |
| 2 | **低负载不许填空**：`load < 0.3` 时 novelty 项归零 | Lavie 2005 | load 从 0.6 降到 0 时分数单调不升 |
| 3 | **硬底线旁路**：floor 取 max，不参与乘法 | 目标/刺激双通道（Awh et al. 2012） | `goalFit=0.05` 的危险项仍占位 |
| 4 | **选择史**：价值学习（正）− 返回抑制（负） | Anderson et al. 2011；Posner & Cohen 1984 | realized↑⇒分数不降；刚被拒⇒分数不升 |
| 5 | **元成本**：每个候选付 `c_meta`；切换成本随 load 加倍 | Russell & Wefald 1991 | 候选数增加时总成本上升；切换被计价 |
| 6 | **判据与敏感度分离**：`β` 由两类错误代价推导 | Green & Swets 1966 | 误接受代价翻倍 ⇒ 阈值单调变严 |

三条容易被误读的地方：

- **定律 1 不是「压力让人变保守」**，而是「压力让人更窄」：它提高的是 `goalFit` 的指数，不是阈值。窄 ≠ 保守；窄可以是更激进地追一个目标。
- **定律 2 与直觉相反**：空闲预算**更容易**被无关内容占满。所以 `novelty` 在低负载下归零，而不是加权。
- **定律 4 是两个机制的差**，不是一个「新奇度旋钮」。一个是正的（付过代价的类别值得再看），一个是负的（刚被拒的不许立刻回看）。把两者合成一个衰减系数，就再也分不清「学乖了」和「被抑制了」。

## 4. 方法论：继承 / 修正 / 反转

这是「从心理学上优化」最有操作性的部分。遇到任何一个人类机制，先问一句：**它对应的是什么约束？Agent 有同样的约束吗？**

- **有** ⇒ **继承**。人类已经用几百万年把它调成了那个约束下的好解。
- **没有，且方向相反** ⇒ **反转**。照抄会把偏见写进协议。
- **没有，但仍然有害** ⇒ **修正**。而且修正的方式应该是**让它在结构上不可能**，不是提醒模型注意。

| 机制 | 人类身上的约束 | Agent 的约束 | 结论 |
| --- | --- | --- | --- |
| chunking、satisficing | 工作记忆 ~4 chunk | 焦点集同样有限 | **继承**（`chunk_weight`、阈值） |
| 返回抑制 | 视觉系统要避免重复采样 | 无生理限制，但重复检索同样浪费 | **继承**（`inhibited`） |
| 边际离场 | 换斑块的旅行成本 | 换目标的上下文重建成本更大 | **继承**（A-8，且 `reentry_cost` 更大） |
| 批处理 | 打断他人有社交成本 | 打断人类仍有成本 | **继承**（P1/P2 分级） |
| 沉没成本 / 承诺升级 | 为已付出的努力辩护 | 无辩护动机，但**预算会诱导继续** | **修正**：结构上禁止用已花费预算参与显著性 |
| 过度自信 | 部分来自社会回报 | 训练目标直接奖励自信表述 | **修正**：置信度上限规则（§8.4） |
| 现在偏差 / 拖延 | 贴现 + 情绪成本 | 无情绪成本，但仍会选近端小奖励 | **修正**：承诺窗口、`abandon_if` 预注册 |
| **少提问** | 提问有面子成本、显得无能 | **没有**这个成本 | **反转**：给"问"定价，而不是假装它害羞 |
| **回避认知努力** | 代谢成本 | 无代谢成本，但**有 token 成本** | **反转**：成本记在 token 上，不记在"努力"上 |
| **低报不确定性** | 社会惩罚不确定性 | 无惩罚，但语言模型天然平滑 | **修正 + 反转**：既要有上限规则，也要允许"我不知道"是免费动作 |

这张表比任何单一公式都更有用。它把「像人一样」从一个形容词变成了一道判断题。

## 5. 实测：模型是能跑的，而且能被推翻

`node tools/cognition-check.ts` 在一条**合成轨迹**上跑两个分配器。隐藏的真实价值只有评分器知道，两个分配器都看不到。

```
metric                      baseline  state-law   +chunks
------------------------------------------------------------------
realised value                 76.80      78.80      58.80
tokens spent                   44880      39270      29000
value per 1k tokens             1.71       2.01       2.03
wasted tokens                   6480        270          0
repeated zero-value picks         46          0          0
hazards missed                     2          0          0
```

- **state-law**：容量钉在 7（与 baseline 相同），只有「闭环」不同。所以这一列隔离的是选择史 + 硬底线。
- **+chunks**：容量也按 chunk 随 load 下降，所以每周期做的事更少。

三个必须一起读的事实：

1. **浪费下降 24 倍**（6480 → 270），重复零价值选择 46 → 0。原因不是先验更好，而是**付过一次代价就记住了**。
2. **危险一个不漏**（2 → 0）。而在 baseline 里，危险项被记成 `low_voi`——日志会声称它「价值低」，而规格说它不该经过这个判断。
3. **绝对产出没有提高**（78.80 vs 76.80），加了 chunk 规则后反而降到 58.80。这是诚实的：模型**拒绝做它学到没有价值的工作**，所以在等周期数下产出更少。效率（1.71 → 2.01）和浪费才是可比的维度。

**底线的价格是测出来的，不是假设的**：

```
hazard 值 0.2：底线每周期亏 0.64
hazard 值 1.0：底线每周期赚回 0.16
```

同一套机制，符号随风险量级翻转。这正是「底线不能用显著性公式算」的量化版本：**它不是一个权重问题，是一个定价问题。**

**这份实验能证明什么、不能证明什么。** 它能证明模型是可计算的、参数是显式的、结论是可推翻的。它**不能**证明真实 Agent 上会有同样的幅度——合成轨迹的 ground truth 是写实验的人定的。任何把上表当性能承诺的读法，都和把 23 分钟当事实是同一种错误。

## 6. 这个模型怎么被证伪

| 若观察到 | 则结论 |
| --- | --- |
| 关掉选择史后，浪费不变 | 定律 4 无效，`history` 应删除 |
| 底线在低价值风险上仍然「划算」 | 底线其实被当成了加权项，不是旁路，实现有误 |
| arousal 升高后目标外候选排序上升 | 定律 1 符号写反 |
| `rest` 撤掉后漏检率不变 | `vigilance` 是装饰，`rest` 只是一个字符串 |
| mastery 分流后成功率不变 | 自我效能应降级为报表字段 |
| 候选数增加 10 倍而总成本不变 | 定律 5 没有生效，元成本没计入预算 |

一个模型的价值不在它解释了多少，而在它**排除了多少**。上表就是它排除的东西。

## 7. 风险，按严重程度

1. **最大的风险是词汇装饰。** 一旦「唤醒」「效能」变成不需要估计量的形容词，这份模型就退化成一偏散文。防线只有一条：§0 的准入门槛 + 每个常量都带 `status: measured | convention`。
2. **参数是约定，不是测量。** 除 `baseCapacity`（Cowan 2001）来自实测外，其余全部标为 `convention`。任何部署都必须用自己的回执重标定，否则只是把一套数字换成了另一套数字。
3. **合成轨迹的说服力被高估。** ground truth 是构造的，优势来自构造。要主张真实收益，需要在带真实回执的轨迹上重跑，并报告 `value per 1k` 与 `wasted_ratio` 的前后差。
4. **心理学效应的迁移性存疑。** 这些范式大多是视觉与空间的；跨到语义与任务内容没有直接证据。因此只借**结构**（该有一个历史项），不借**数值**（历史项该有多大）。
5. **三层模型本身可能是过度拟合。** 三个层次是对现有文献的一种整理，不是文献的定论。若某一层找不到独立的状态变量，就合并——不要为了对称保留三个。

## 8. 与七条不变量的对应

| 层 | 不变量 | 本文提供的理由 |
| --- | --- | --- |
| 容量层 | A-7（chunk 容量）、A-12（在任务时长与切换） | 无复述容量 ≈ 4；切换有独立成本；警戒衰减是漏检率而非能量 |
| 评价层 | A-8（边际离场）、A-9（判据由代价推导）、A-10（底线旁路）、A-11（元成本） | 边际价值定理；SDT 的两个参数；目标/刺激双通道；元推理有成本 |
| 自我-社会层 | A-6（选择可复现）、W-6（校准二分）、D-11…D-13（团队三规则） | 选择史是第三类驱动；`d'` 与 `c` 分离；可识见性、共享信息偏差、交互记忆 |

一句话：**先有约束，才有公式。** 公式里的每个符号都应该能回答「如果没有这个约束，它是否还成立」；答不上的符号，就该删掉。
